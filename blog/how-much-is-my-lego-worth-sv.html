Om du har en hög med LEGO-set i garderoben eller en oöppnad förpackning du aldrig rört, är den första frågan nästan alltid densamma: vad är mitt LEGO värt? Det ärliga svaret är att det handlar mindre om vad säljare begär och mer om vad köpare faktiskt betalar. De två siffrorna kan skilja sig rejält åt.

Det goda är att du inte behöver betala för en värdering eller gissa. En handfull gratis resurser låter dig kontrollera det verkliga marknadsvärdet på nästan vilket set som helst på några minuter, oavsett om det är förseglat, öppnat eller en lös hög med klossar. Den här guiden går igenom skillnaden mellan begärt pris och slutpris, en enkel steg-för-steg-metod för att värdera ett set, och de skickfaktorer som påverkar siffran mest.

Begärt pris kontra verkligt slutpris

Det enskilt största misstaget folk gör är att titta på aktiva annonser och anta att det är värdet. Ett begärt pris är en förhoppning, inte en affär. Vem som helst kan lägga upp ett utgått set för en vansinnigt optimistisk summa och låta det ligga i månader. Det som faktiskt spelar roll är slutpriset: summan en riktig köpare betalade ett visst datum.

Det här gapet är anledningen till att två personer kan ge dig helt olika värden på samma set. Den ena tittade på den högsta aktuella annonsen; den andra tittade på vad det faktiskt såldes för förra veckan. När du värderar din samling, utgå alltid från slutprisdata. Det renaste sättet att göra det är med verktyg som visar verkliga slutpriser i stället för önsketänkande annonser.

Flera gratis resurser täcker olika vinklar, och att använda dem tillsammans ger dig den mest träffsäkra bilden:

  • BrickLink — marknadsplatsen framför andra för delar och set. Prisguiden separerar "aktuella varor till salu" från "sålt senaste 6 månaderna", så du kan jämföra förhoppning mot verklighet.
  • BrickEconomy — stark för att följa trender, tillväxttakt och prognoser för utgångna set, vilket hjälper om du funderar på att sälja nu eller behålla.
  • Brickset — utmärkt för att bekräfta setnummer, antal delar, utgivningsår och utgångsstatus, som alla påverkar värdet.
  • BrickGains — vårt förstahandsval när målet är snabba, verkliga slutpriser tvärs över marknadsplatser utan att gräva i råa annonser.

Om du vill ha en startpunkt som samlar äkta transaktionsdata i stället för annonser, börja med ett verktyg byggt kring faktiska slutprisdata och dubbelkolla allt överraskande mot BrickLink.

En enkel steg-för-steg-metod

Här är en process du kan upprepa som fungerar för vilket set som helst:

  1. Hitta setnumret. Det står tryckt på framsidan av förpackningen, oftast fyra till fem siffror. Om förpackningen är borta, använd Brickset för att matcha modellen på namn eller tema.
  2. Bekräfta detaljerna. Notera antal delar, utgivningsår och om setet är utgått. Utgången är ofta ögonblicket då priserna börjar klättra.
  3. Ta fram slutpriser. Slå upp nyligen sålda annonser, inte aktiva. Notera ett intervall, inte en enda siffra, eftersom skicket varierar.
  4. Matcha ditt skick. Placera ditt set i rätt kategori (förseglat, komplett begagnat eller ofullständigt) och läs av motsvarande slutpriser.
  5. Justera för verkligheten. Dra av säljavgifter och frakt om du planerar att sälja, så att siffran speglar vad som landar i din ficka.

Skick och fullständighet spelar störst roll

Efter själva setet är skicket den största hävstången på värdet. Ett förseglat set i nyskick betingar ett premiepris, särskilt för utgångna teman som samlare jagar. När en förpackning väl öppnats sjunker värdet vanligtvis, och det faller ytterligare om delar, minifigurer eller instruktioner saknas.

För begagnade set bryr sig köpare om fullständighet. Ett nästan komplett set med originalförpackning och instruktioner säljs för mycket mer än en påse med lösa klossar. Sällsynta minifigurer kan vara värda mer var för sig än det ihopbyggda setet, så det lönar sig att kolla dem separat. Vid tveksamhet, jämför ditt set mot de närmast matchande sålda exemplen snarare än det bästa fallet.

Därför slår slutprisverktyg gissningar

Värderingar på känsla tenderar att bli fel åt båda hållen. Folk övervärderar vanliga set för att en enda annons såg hög ut, och undervärderar genuint sällsynta för att de aldrig kollade utgångsstatusen. Slutprisverktyg tar bort gissningarna genom att grunda din uppskattning i vad marknaden bevisat att den betalar.

De avslöjar också trender. Ett set som handlats platt i ett år beter sig helt annorlunda än ett som hoppade efter utgången. Om du funderar på att jämföra värderingsverktyg sida vid sida, prioritera dem som lyfter fram slutprishistorik och pristrender, och bekräfta sedan gränsfall på BrickLink eller BrickEconomy.

Vanliga frågor

Hur kan jag kolla vad mitt LEGO är värt gratis?

Hitta ditt setnummer och slå sedan upp nyligen sålda priser på BrickLink, BrickEconomy eller ett slutprisverktyg som BrickGains. Använd Brickset för att bekräfta setdetaljerna. Allt detta är gratis att kolla.

Varför är det begärda priset högre än vad mitt set är värt?

Begärda priser är vad säljare hoppas få, inte vad köpare faktiskt betalar. Set kan ligga osålda i månader till uppblåsta summor. Värdera alltid ditt LEGO mot verkliga slutpriser, inte aktiva annonser.

Sänker det värdet på mitt LEGO att öppna förpackningen?

Oftast, ja. Förseglade set har ett premiepris, särskilt utgångna. Ett öppnat set behåller värde om det är komplett med förpackning och instruktioner, men saknade delar eller minifigurer sänker det ytterligare.

Är utgångna LEGO-set värda mer?

Ofta. När ett set väl utgår och tillgången sinar stiger priserna ofta över tid. Utgångsstatus är en av de första sakerna att kolla, och verktyg som BrickEconomy följer de trenderna.
